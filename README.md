# bank_pokypok_2

React MVP для проекта **«Банк покупок / Калык шынык»**.

## Что уже реализовано

- 4 страницы: Главная / Каталог / Квест / Профиль.
- 5 уровней квеста с проверкой QR-кода, загрузкой фото/видео и вопросами на ключевых этапах.
- Прогресс-бар по уровням и выдача награды по скорости прохождения.
- Каталог с выбором товара и мок-интеграцией платежей (VTB Pay, Sber Pay, Stripe, PayPal).
- Мультиязычность: RU / EN / MAR.
- Цветовая палитра: `lightgreen`, `lightyellow`, `lightpink`.

## Запуск

```bash
npm install
npm run dev
```


> Важно: `index.html` не открывайте напрямую двойным кликом из файловой системы.
> Запускайте через dev-сервер Vite: `npm run dev`.
> Если видите только "Загрузка приложения…" и ничего не происходит — скорее всего открыт файл через `file://`, а не dev-сервер.

## Сборка

```bash
npm run build
```

## Что делать, если PR не создаётся

1. Проверь, что есть коммит:
   ```bash
   git status --short
   git log --oneline -n 3
   ```
2. Убедись, что ветка не `main` и в ней есть новые изменения.
3. Проверь доступы (token/SSH/права в репозитории) и что remote корректный:
   ```bash
   git remote -v
   ```
4. Если ошибка связана с сетью или политиками безопасности CI/CD — попробуй создать PR вручную в GitHub/GitLab UI.
5. Для этого окружения: если `make_pr` падает, сначала сделай `git commit`, затем повтори вызов инструмента `make_pr`.
